# vampn

Mobile app lives in [`mobile/`](mobile). Server-side code can be added later beside that folder.

GitHub Actions:

- [`.github/workflows/android.yml`](.github/workflows/android.yml) builds debug and release APKs on the React Native community Android image.
- [`.github/workflows/ios.yml`](.github/workflows/ios.yml) builds the iOS app on a macOS runner.
